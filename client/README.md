# feuer client

React/Vite/Pixi client for the multiplayer RTS prototype. Install dependencies from the repository root; see [the root README](../README.md) for branch differences, environment setup, build checks and local-server limitations.

```bash
npm run build --workspace=client
npm run lint --workspace=client
```

The [portfolio-demo specification](../docs/project-readiness.md) defines the proposed next milestone. The current client is not a finished game or a standalone static demo.
